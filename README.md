# 企业材料预审 · 本机试用版

## 打开

运行 `start.ps1`，再访问 http://127.0.0.1:8765 。
仅绑定本机回环地址，不支持其他电脑访问。不要直接用作公网生产服务。

体验账号：

| 入口 | 账号 | 密码 |
| --- | --- | --- |
| 员工 | employee | Employee2026! |
| HR | hr | Hr2026! |

登录页可直接填入对应账号。体验账号为本机试用专用，尚未接入企业单点登录、
员工开户、密码管理和多租户管理。正式接收员工个人材料前必须补齐这些能力。

## 当前已实现

- 五类材料、八个必需子项齐全后统一上传，服务端独立复验。
- 同一合并文件可用于多个子项，按内容去重；单文件 15 MB、整套 45 MB / 60 页。
- 本地 PDF 文字层提取和扫描件 OCR。没有接入外部模型或远端验真。
- 明确匹配到违反企业规则时自动退回，展示原因及原件页码。
- 识别不确定转 HR 人工复核。人工确认、退回、补正及申诉留存处理记录。
- 补正保留之前文件；更新问题文件后整套重新检查，并保留旧版本。
- 员工与 HR 权限区分；文件预览需登录及对应申请访问权限。

## 规则

- 劳动合同：明确起始年份为 2026；签署日期不替代起始日期。
- 身份证：正反面关键字段位于同一页。
- 社保：明确查询区间起始月份为 2025 年 1 月，不看首次参保日期。
- 无房：三个指定登记栏目结果均为“无”；可识别页码时检查完整性。
- 学历：学历证书、学位证书、学历及学位验证报告，毕业年份为 2026。
- 学籍报告不可替代学历或学位报告。

规则为用户指定的企业预审口径，不作为官方资格判定。

## 必须人工处理的部分

身份一致性、照片完整性、打码/遮挡、伪造、原件真实性、缺少可靠日期标签的合同、
非标准版式和低置信度 OCR 均须人工核对。OCR 阈值不是文档真实性置信度。
PDF 文字层也不能证明内容真实。不对扫描件识别准确率作生产承诺。
不自动作出最终资格否决，用户可申请人工复核。

## 数据位置与限制

文件、预览和 SQLite 数据保存在项目 `work/hr-private/`，不是 `outputs/`。
未提交文件仅保留在网页内存，刷新会清空。没有外发员工材料。
原件和识别文字在本地以普通文件保存，尚无应用层加密、自动删除、备份策略、
完整审计防篡改或生产级身份管理。请先用虚构材料体验。
已提供“载入测试材料”，所有样本均标注为虚构测试，不包含真实身份证号码或印章。

## 依赖与测试

Python 3.12；PyMuPDF、Pillow，以及工作目录内安装的 rapidocr_onnxruntime。
图标使用本地 Lucide；网页无需从外部 CDN 加载资源。

`python -m unittest discover -s outputs/hr-review -p test_rules.py -v`

本地运行路径以本项目当前目录结构为准。将文件迁到其他电脑前需重新安装依赖。
